Eco Garden - AI Powered Sustainability Minigame

View Code on GitHub

Eco Garden is an AI-powered sustainability minigame developed for CloudHacks 2024, a student-led hackathon that took place on June 22-23, 2024. The project combines gamification with artificial intelligence to encourage sustainable habits and environmental awareness through an engaging interactive experience.

The application features a full-stack architecture with user authentication, social features like posts and leaderboards, and an AI-powered minigame that uses Google Gemini AI to create dynamic, educational content about sustainability. Users can register, create profiles, interact with the community through posts, compete on leaderboards, and play the sustainability minigame.

Built during a 24-hour hackathon, this project demonstrates rapid development skills, teamwork, and the ability to integrate AI technologies into a functional web application. The project showcases full-stack development capabilities, API integration, database design, and user experience design.

🏆 Hackathon Project

This project was developed for CloudHacks 2024, a hybrid hackathon that took place on June 22-23, 2024. CloudHacks is a student-led hackathon aiming to unite programmers from around the country, providing an opportunity for like-minded students to learn, innovate, and network through workshops and hacking.

🤖 AI-Powered Minigame

The core feature of Eco Garden is an AI-powered sustainability minigame that uses Google Gemini AI to create dynamic, educational content. The game engages users with interactive challenges and questions about sustainability, with AI-generated responses that adapt to user interactions.

  • Google Gemini Integration: Integrated Google's Gemini AI API to power the minigame, enabling dynamic content generation and intelligent responses to user actions.
  • Interactive Gameplay: Created an engaging game interface that combines educational content about sustainability with gamification elements to encourage user participation.
  • Dynamic Content: The AI generates contextual responses and challenges based on user progress and interactions, making each gameplay experience unique.

👤 User Features

The application includes comprehensive user management and social features to create an engaging community around sustainability.

  • User Authentication: Secure registration and login system using JWT tokens and Bcrypt password hashing for enhanced security.
  • User Profiles: Users can create and edit profiles, view their game progress, and track their sustainability achievements.
  • Social Posts: Community feature allowing users to create and share posts about sustainability topics, fostering engagement and discussion.
  • Leaderboards: Competitive element that displays top performers, encouraging users to improve their sustainability scores and engage more with the platform.

🏗️ Technical Architecture

The project follows a clean, modular architecture with separation of concerns for maintainability and scalability.

  • Backend Structure: Organized into controllers, models, routes, and services for clean code organization and maintainability.
  • Database Schema: Designed and implemented MySQL database schema for users, posts, game data, and leaderboard information.
  • API Design: RESTful API endpoints for game operations, user management, post creation, and leaderboard functionality.
  • Security: Implemented JWT-based authentication, password hashing with Bcrypt, and secure API endpoints.
  • Frontend Integration: Seamless integration between frontend JavaScript and backend APIs using Fetch API and async/await patterns.

📦 Dependencies & Setup

The project uses modern Node.js technologies and requires proper configuration for database and AI API access.

  • Backend: Express.js for server framework, MySQL2 for database connectivity, dotenv for environment configuration
  • Authentication: jsonwebtoken for JWT tokens, bcrypt for password hashing
  • AI Integration: @google/generative-ai for Gemini AI API integration
  • Development: Nodemon for development server with hot reloading
  • Configuration: Environment variables for database credentials, JWT secrets, and API keys
