Mini Student Management System

This project involved developing a comprehensive student management system using Java OOP, Swing GUI, and file I/O. The system simulates a real student information platform capable of displaying student profiles, navigating modules, searching by name or class, computing GPA, and managing student records with data persistence.

I designed the application using object-oriented principles, creating a Module class to store module code, name, credit units, and marks, and a Student class to store class, admin number, student name, GPA, and an array of modules. The StudentManagement class manages all student operations, providing a clean separation of concerns and maintainable code structure.

I built an intuitive Java Swing GUI interface using JLabel, JTextField, JTextArea, JButton, and other Swing components. The interface allows users to switch between students and modules easily, with panels updating dynamically based on user actions. Users can display all students on program start, navigate between students using Previous/Next buttons, navigate between modules for each student, and search by class or name to load specific student records.

🎯 Core Features

The system provides comprehensive functionality for managing student information:

  • Display all students with their profiles, modules, and GPA
  • Navigate between students and their modules
  • Search by name or class with validation
  • Compute GPA using official GPA weighting formulas
  • Create, update, and delete student records
  • Add modules to existing students dynamically
  • Save and retrieve data using text file I/O for data persistence
  • Class statistics showing number of students and average GPA

🖥️ GUI Application Features

I expanded the base system into a full Java Swing GUI application with comprehensive admin functionalities and file I/O support.

User Functions

  • Display all students on program start
  • Navigate between students (Previous / Next buttons)
  • Navigate between modules for each student
  • Search by class → loads first student + class statistics
  • Search by name → loads exact student record
  • Exit button with thank-you message

Admin Functions

  • Create New Student: Enter name, admin number, class, and add modules dynamically
  • Add Modules to Existing Student: Search by name or admin number and append new module(s)
  • Delete Student: Search for student and remove from array with validation and feedback
  • Save to File on Exit: Write all student and module data to students.txt for data persistence across sessions

🏗️ Object-Oriented Architecture

The system is built using object-oriented programming principles with a well-structured class hierarchy:

  • Module Class: Stores module code, name, credit units, and marks
  • Student Class: Stores class, admin number, student name, GPA, and an array of modules
  • StudentManagement Class: Manages all student operations including search, CRUD operations, and data management
  • Main Program: Handles user interaction and coordinates between GUI components and data management

This architecture ensures code reusability, maintainability, and follows OOP principles such as encapsulation, inheritance, and polymorphism.
