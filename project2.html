Mini Student System

I created a Java Swing application to manage student information with search and CRUD functionality.

For this Java Programming module project, my team and I enhanced an existing Mini Student System by building a more robust and user-friendly Java Swing GUI. The system allows users to display, search, add, and delete students and their module records, making it a functional student information management tool.

I designed and implemented the GUI using components like JLabel, JTextField, JButton, and JCheckBox, ensuring clear navigation and ease of use. Key features include:

  • Searching for students by class or name
  • Displaying GPA calculations and module statistics
  • Managing student and module records with validation
  • Error handling for missing or invalid inputs

Additionally, I implemented file I/O operations, enabling the application to read and store student data in text files, ensuring persistence across sessions.

Key Features & Technologies

  • Java Swing GUI design
  • CRUD operations for student & module data
  • Search functionalities (by class or name)
  • Text file I/O for persistent storage
  • Object-oriented programming & data encapsulation

Skills Developed

  • OOP design & problem-solving
  • GUI development and layout design
  • File handling and data persistence
  • Team collaboration and version control
