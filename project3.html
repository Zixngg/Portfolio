E-Commerce Web Application

A database-driven application demonstrating backend logic, SQL development, and analytics features.

This project focused on creating a functional e-commerce backend system with strong emphasis on database design, SQL development, and data processing. I designed database tables to support products, customers, transactions, reviews, and analytics.

I implemented CRUD operations, user-defined SQL functions, and stored procedures to handle real-world business logic. Examples include:

  • Calculating running total spending for each customer
  • Computing Customer Lifetime Value (CLV)
  • Generating review summaries
  • Admin analytics to compare spending across age groups

Robust error handling and logical constraints were included to ensure data integrity. The project also required use of version control, SQL best practices, and structured documentation.

Key Features & Technologies

  • SQL database schema design (tables, relationships, constraints)
  • CRUD operations & stored procedures
  • Functions for CLV, reviews, and total spending
  • Admin analytics for customer segmentation
  • Version control (Git) and collaborative workflow

Skills Developed

  • Database normalization and ERD planning
  • Advanced SQL functions and procedures
  • Backend data processing
  • Analytical thinking using real-world business metrics
