Restaurant Management System

View Code on GitHub View Live Application

This project involved developing a full-stack restaurant management system with a focus on CI/CD implementation, automated testing, and real-world features. I worked on multiple components including admin menu management, delivery tracking, image uploads, and state management.

I implemented a comprehensive filtering system for admin menu management, allowing admins to easily access specific menu items and upload photos. For the delivery option, I was inspired by popular delivery apps like Grab, Food Panda, and Shopee, implementing real-time delivery tracking where users can monitor their delivery progress status.

The project required integration across frontend, backend, and database components, ensuring seamless interaction and functionality. I also implemented a proper CI/CD pipeline using GitHub Actions, with automated testing using Playwright to ensure code quality and system reliability.

🍽️ Admin Menu Management

I implemented a comprehensive menu management system for admins, allowing them to efficiently manage menu items with advanced filtering capabilities and image uploads.

  • Advanced Filtering System: Created a filtering system that allows admins to filter menu items by category, price range, stock range, and sort by price or stock levels. The system dynamically constructs query strings with only non-null parameters to optimize backend queries.
  • Image Upload Functionality: Implemented image uploads for menu items using Multer, allowing admins to upload and update photos of menu items to improve visual representation. This required handling asynchronous image uploads and file management.
  • Real-Time UI Updates: Ensured that displayed menu items are dynamically refreshed without requiring a full page reload, providing a smooth user experience.
  • Data Transformation: Processed input from form fields and dynamically updated displayed menu items by fetching data based on selected criteria, ensuring accurate filtering and performance optimization.

🚚 Real-Time Delivery Tracking System

I designed and implemented a delivery order tracking system inspired by popular delivery apps, providing users with real-time updates on their delivery progress.

  • State Management: Implemented delivery order states including "ASSIGNED", "PICKED_UP", "IN_TRANSIT", and "COMPLETED". Admins can update delivery status through a drag-and-drop interface, and changes reflect immediately on the user side.
  • Real-Time Status Updates: Created a system that provides live updates to users, ensuring they receive immediate notifications when their delivery status changes. This required multiple API calls to ensure real-time synchronization.
  • Delivery Confirmation Images: When a delivery is completed, admins can upload a delivery confirmation image showing where the order was placed. This image is displayed to users, providing visual confirmation of delivery completion.
  • User Experience: The tracking system improves customer satisfaction by providing transparency and real-time visibility into the delivery process, similar to popular delivery platforms.

🔄 Full-Stack Development

This project required seamless integration across frontend, backend, and database components. I worked on multiple full-stack features that required meaningful changes across different layers of the application.

  • User Authentication System: Implemented JWT-based authentication, ensuring secure login/logout sessions. Handled token expiration and user session management dynamically, with proper admin redirection to the correct dashboard.
  • Backend API Development: Created RESTful APIs to support menu management, delivery tracking, and order processing. Implemented proper error handling and data validation throughout.
  • Database Integration: Stored delivery status updates and delivery information in the database, allowing persistent order tracking across sessions.
  • Frontend-Backend Communication: Ensured smooth data flow between frontend and backend, handling asynchronous operations and state synchronization effectively.

📊 Data Transformation & Filtering

I implemented a menu filtering system for the Admin Menu Management panel that required sophisticated data transformation to display only relevant items based on selected criteria.

  • Category-Based Filtering: Uses the selected categoryId to fetch only menu items belonging to that category, optimizing database queries.
  • Price and Stock Filtering: Allows filtering menu items within specific price and stock ranges, giving admins flexible search capabilities.
  • Sorting Options: Supports sorting items by price or stock, allowing admins to organize displayed results according to their needs.
  • Dynamic Query Handling: Constructs API calls efficiently by excluding empty filters, optimizing backend request performance and reducing unnecessary data retrieval.
  • Real-Time Updates: The applyFilters function processes input from form fields and dynamically updates displayed menu items, ensuring the UI reflects current filter selections instantly.

🧪 CI/CD Pipeline & Automated Testing

I implemented a proper CI/CD pipeline using GitHub Actions, which automated the testing and deployment process. The pipeline ensured code quality and system reliability through automated testing.

  • GitHub Actions Workflow: Created a structured CI/CD pipeline that automated testing and deployment. Every commit triggered automated testing, and if tests failed, deployment was halted to ensure only stable code was deployed.
  • Automated Testing with Playwright: Implemented comprehensive test cases including:
    • Admin Menu Management Tests (page loading, add/edit/delete menu items)
    • User Authentication Tests (login, admin redirection, error handling)
    • User Registration Tests (account creation, duplicate validation)
  • Containerized Testing: Standardized test execution using containerized Playwright testing to ensure consistent results across different environments.
  • Database Transaction Management: Implemented database transaction rollbacks in test cases to handle inconsistent database states and ensure test reliability.
  • Azure Deployment: The application was deployed to Azure App Service, ensuring high availability. Environment variables were securely managed using GitHub Secrets.
  • GitHub Flow: Followed best practices with feature branches, pull requests, and code reviews before merging to main branch.

📸 Image Upload with Multer

I implemented image upload functionality using Multer, which allowed seamless integration of delivery confirmation images and menu item photos into the system.

  • Menu Item Images: Admins can upload and update photos for menu items, improving the visual representation of the menu and enhancing user experience.
  • Delivery Confirmation Images: When deliveries are completed, admins can upload images showing where the order was placed, providing visual confirmation to customers.
  • Asynchronous Handling: Managed asynchronous image uploads effectively, ensuring smooth user experience during file uploads.
  • File Management: Implemented proper file storage and retrieval, ensuring images are properly associated with menu items and delivery orders.
