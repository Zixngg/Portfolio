Gamified Sustainability Task Tracker

A full-stack web application designed to gamify eco-friendly habits.

View Code on GitHub

This project involved developing a gamified task-tracking website that encourages users to adopt sustainable habits through interactive challenges and reward systems. The goal was to make environmentally friendly actions more engaging by allowing users to complete tasks, earn points, unlock creatures/items, and track their progress in a visually appealing interface.

I implemented user authentication using JWT (JSON Web Tokens) and strengthened security through Bcrypt password hashing. Users can register, log in, view profiles, and manage in-app features securely. The platform also includes a global messaging feature, enabling users to send and receive messages using backend APIs.

The frontend was built using Bootstrap for responsive design, and Fetch API / Axios / jQuery for seamless frontend-backend communication. The vibrant fantasy-themed UI enhances user engagement, and the dashboard integrates inventory, creatures, rewards, and task completion data.

Key Features & Technologies

  • JWT-based authentication / Bcrypt password hashing
  • User profile view with points, items, and progression tracking
  • Messaging system with backend integration
  • Bootstrap for responsive UI
  • RESTful API communication via Fetch API / Axios / jQuery

🔐 Secure Authentication & User Management

I implemented a complete authentication flow using JWT (JSON Web Tokens) and bcrypt, ensuring that user data and sessions are managed securely.

  • JWT Middleware: Validates tokens before allowing access to actions like completing tasks or purchasing items. Tokens expire every 15 minutes for improved security.
  • Password Hashing with Bcrypt: User passwords are salted and hashed before storage, ensuring no plaintext passwords exist in the database.

🧩 Backend Architecture & Routing

The backend routes requests based on HTTP methods (GET, POST, PUT, DELETE) and endpoints. Middleware is used to compare passwords, validate tokens, handle form submissions, and manage CRUD operations (e.g., tasks, creatures, messages).

Form submissions on the frontend get processed and stored in the backend—for example, posting a message, purchasing an item, or registering/logging in.

✉️ Global Messaging System

A fully functional messaging page allows users to post global messages, edit or delete their own messages, and view messages from all users. This demonstrates CRUD operations, DOM manipulation, and API integration via Fetch API.

📦 Fantasy-Themed Creatures, Items & Inventory System

Users can buy creatures and items using points earned from tasks. I created multiple dynamic pages for viewing all creatures/items, viewing details of a specific creature/item, purchasing based on point validation, and updating user inventory.

Error handling was implemented to ensure the user is notified if they do not have enough points, a purchase succeeds, or a creature cannot be found.

🎨 UI/UX & Visual Design

The website uses a consistent purple fantasy theme, with the Audiowide font to enhance the game-like feeling. User profile sections are clearly segmented (Items vs. Creatures), forms and buttons are cleanly labelled, and messaging textbox is placed at the top for clarity. Backgrounds and component layouts follow an immersive theme.

🧠 Modular Frontend & JavaScript Logic

I practiced modularity by reusing similar structures across HTML files and maintaining consistent GET/POST logic across JavaScript components. This includes extracting URL parameters (e.g., creature_id), fetching data from backend, displaying conditional UI elements, and showing purchase buttons only when appropriate.

🔗 Frontend–Backend Integration

All interactions between pages and the server were handled through a custom fetchMethod(url, method, data) wrapper, supporting GET (retrieve creatures, items, messages, tasks), POST (create messages, register users, login), PUT (edit tasks/messages), and DELETE (remove creatures/messages). This enhanced scalability and minimized repeated code.
